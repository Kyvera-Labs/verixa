# Verixa documentation

Verixa is open-source infrastructure for authentication, authorization,
identity, verification, audit logging, security, and governance. These pages
are the same Markdown files that live in [`docs/`](https://github.com/Kyvera-Labs/verixa/tree/main/docs)
in the repository; the sidebar lists every one of them.

## Where to start

- **Contributing code:** [Testing the platform](./guides/tutorials/testing-the-platform.md)
  walks through every kind of test the repository uses, and
  [Domain modeling](./guides/domain-modeling.md) explains the layering the
  lint rules enforce.
- **Building with Verixa:** the [tutorials](./guides/tutorials/build-the-identity-context.md)
  build each bounded context step by step.
- **Why it is built this way:** the [architecture decision records](./adr/0000-adr-process.md).
- **Security design:** start with [authentication flows](./security/authentication-flows.md)
  and the [threat register](./security/threat-register.md).
- **Writing docs:** [how to add a page to this site](./guides/writing-docs.md).
